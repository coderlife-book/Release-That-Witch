# Release That Witch — 3D 关系图谱

基于 Three.js 的《放开那个女巫》互动关系图谱。

当前数据严格以阅读进度 **“温蒂测试滑翔之翼”** 为剧透边界：只展示此前已经明确的人物、组织、地点、国家与关系，不提前揭示后续身份、结局、势力变化或伏笔回收。

## 目标

- 以罗兰为中心浏览人物关系
- 同时表达人物、女巫组织、市政体系、地区、国家与教会势力
- 支持阵营/类型/层级筛选、搜索、聚焦与详情查看
- 数据层与 Three.js 渲染层分离，后续阅读进度更新只需要补充数据

项目代码正在 `feat/knowledge-graph-v1` 分支构建。
